# Parmigiano v1

Package: `parmigiano.v1`.

| File | Role |
| --- | --- |
| `v1/common.proto` | Types shared by both sides |
| `v1/client.proto` | Packets sent by the client |
| `v1/server.proto` | Packets sent by the server |

## Wire format

Each packet is a big-endian `uint32` length followed by one serialized protobuf message. The length is the number of protobuf bytes and does not include the 4-byte prefix.

The client sends `ClientMessage`. The server sends `ServerMessage`. Exactly one `payload` branch is set. Field numbers inside a message are part of the wire contract.

---

## common.proto

### ContentType

Kind of a chat message body.

| Value | Meaning |
| --- | --- |
| `CONTENT_TYPE_UNSPECIFIED` | Zero value. Not a valid body. |
| `CONTENT_TYPE_TEXT` | Text. `content` is the message text. |
| `CONTENT_TYPE_IMAGE` | Image. `content` is the object storage key. |
| `CONTENT_TYPE_VIDEO` | Video. `content` is the object storage key. |
| `CONTENT_TYPE_FILE` | File. `content` is the object storage key. |
| `CONTENT_TYPE_VOICE` | Voice. `content` is the object storage key. |

`CONTENT_TYPE_MEDIA` is reserved and is not a valid body.

### FileInfo

One file in a client install.

| Field | Type | Meaning |
| --- | --- | --- |
| `name` | `string` | File name. |
| `path` | `string` | Path relative to the install. |
| `hash` | `string` | Content hash. |

### DirInfo

One directory. `path` is the directory path.

### MainExecutable

File name of the client's main executable. `name` is that file name.

### FileSet

Snapshot of an install: `files`, `directories`, and `main_executable`. The client sends this snapshot as `ClientMessage.file_hashes` (what it currently has). The server sends it as `ServerMessage.file_manifest` (what the client should update to).

---

## client.proto

`user_id` on `ClientMessage` is the sender. Payloads do not repeat it.

### ClientMessage

Client envelope. `user_id` identifies the sender. `payload` is exactly one of the messages below.

### Connect

First packet after the connection is established. `public_key` is the client's public key.

### PublicKeyRequest

Asks for the public key stored for `user_id`. The server answers with `PublicKey`. `ClientMessage.user_id` remains the sender and is not this field.

### PresenceRequest

Online state of `ClientMessage.user_id`. `online` is `true` when the user is online and `false` when the user goes offline.

### SendMessageRequest

New chat message.

| Field | Type | Meaning |
| --- | --- | --- |
| `chat_id` | `uint64` | Target chat. |
| `content` | `string` | Text, or the object storage key when `content_type` is not `CONTENT_TYPE_TEXT`. |
| `content_type` | `ContentType` | How to interpret `content`. |
| `temp_message_id` | `uint64` | Id generated by the client. The server returns it on `MessageCreated`. |

### ReadMessageRequest

The sender has read a message. `chat_id` is the chat. `message_id` is the message.

### EditMessageRequest

Replace the body of an existing message. `chat_id` and `message_id` select it. `content` and `content_type` follow the same rules as `SendMessageRequest`.

### PinMessageRequest

Pin or unpin a message. `pinned` is `true` to pin and `false` to remove the pin.

### DeleteMessageRequest

Delete a message. `chat_id` and `message_id` select it.

### TypingRequest

Typing state in a chat. `is_typing` is `true` while the user is typing and `false` when the user stops.

### UnreadCountRequest

Asks how many messages in `chat_id` are unread for `ClientMessage.user_id`. The server answers with `UnreadCount`.

### DownloadFileRequest

Asks the server for one update file. `path` is the file path. The server answers with `DownloadFileResult`.

---

## server.proto

### ServerMessage

Server envelope. `payload` is exactly one of the messages below.

### PresenceEvent

Online state of a user. `user_id` is that user. `online` is the new state.

### TypingEvent

Typing state of a user in a chat. `user_id` is that user. `chat_id` is the chat. `is_typing` is `true` while typing and `false` when typing stops.

### MessageCreated

A message was stored and can be shown.

| Field | Type | Meaning |
| --- | --- | --- |
| `temp_message_id` | `uint64` | Id from `SendMessageRequest`. `0` for everyone except the sender. |
| `message_id` | `uint64` | Server id of the message. |
| `chat_id` | `uint64` | Chat the message belongs to. |
| `sender_id` | `uint64` | Author. |
| `content` | `string` | Text, or the object storage key when `content_type` is not `CONTENT_TYPE_TEXT`. |
| `content_type` | `ContentType` | How to interpret `content`. |
| `created_at` | `Timestamp` | Time the message row was created. |
| `is_edited` | `bool` | The stored message has been edited. |
| `is_pinned` | `bool` | The stored message is pinned. |

### MessageRead

A user has read a message. `chat_id` and `message_id` select it. `user_id` is the reader. `read_at` is when that read was stored. The same packet is the read receipt for the author.

### MessageEdited

A message body was replaced.

| Field | Type | Meaning |
| --- | --- | --- |
| `message_id` | `uint64` | Edited message. |
| `chat_id` | `uint64` | Chat. |
| `sender_id` | `uint64` | Author of the edit. |
| `content` | `string` | New body. |
| `content_type` | `ContentType` | How to interpret `content`. |
| `edited_at` | `Timestamp` | Time of the edit. |

### MessageDeleted

A message was deleted.

| Field | Type | Meaning |
| --- | --- | --- |
| `chat_id` | `uint64` | Chat. |
| `message_id` | `uint64` | Deleted message. |
| `user_id` | `uint64` | Who deleted it. For moderation this is the acting user, or empty when there is none. |
| `deleted_at` | `Timestamp` | Time the deletion was stored. |
| `reason` | `MessageDeleted.DeleteReason` | Why it was deleted. |

`MessageDeleted.DeleteReason`:

| Value | Meaning |
| --- | --- |
| `DELETE_REASON_UNSPECIFIED` | Zero value. Reason was not set. |
| `DELETE_REASON_USER` | Deleted by a user. |
| `DELETE_REASON_MODERATION` | Removed by moderation. |

### MessagePinned

Pin state of a message. `user_id` is who changed it. `chat_id` and `message_id` select the message. `pinned` is `true` when the message is pinned and `false` when the pin is removed.

### UnreadCount

Answer to `UnreadCountRequest`. `chat_id` is the chat. `count` is the number of unread messages.

### PublicKey

Answer to `PublicKeyRequest`. `user_id` is the key owner. `public_key` is that user's public key.

### Disconnect

The server is closing the connection.

| Field | Type | Meaning |
| --- | --- | --- |
| `reason` | `Disconnect.DisconnectReason` | Why the connection is closed. |
| `description` | `string` | Human-readable detail. |
| `code` | `int32` | Application-specific code. |
| `blocked_until` | `Timestamp` | End of a temporary account ban. Unset when the ban is not temporary. |
| `permanent` | `bool` | The account ban does not expire. |

`Disconnect.DisconnectReason`:

| Value | Meaning |
| --- | --- |
| `DISCONNECT_REASON_UNSPECIFIED` | Zero value. Reason was not set. |
| `DISCONNECT_REASON_WARN` | Warning. |
| `DISCONNECT_REASON_ERROR` | Error. |
| `DISCONNECT_REASON_TEMP_BAN` | Temporary ban. |
| `DISCONNECT_REASON_INACTIVE` | Connection is idle. |
| `DISCONNECT_REASON_INSUFFICIENT_INFO` | The client did not send required data. |

### DownloadFileResult

Answer to `DownloadFileRequest`. `file` is the `FileInfo` of the requested file.

# Parmigiano v1

Пакет: `parmigiano.v1`.

| Файл | Роль |
| --- | --- |
| `v1/common.proto` | Общие типы обеих сторон |
| `v1/client.proto` | Пакеты клиента |
| `v1/server.proto` | Пакеты сервера |

## Формат на проводе

Каждый пакет — это длина `uint32` в порядке big-endian и сразу за ней одно сериализованное protobuf-сообщение. Длина считает только байты protobuf и не включает сами 4 байта префикса.

Клиент отправляет `ClientMessage`. Сервер отправляет `ServerMessage`. Заполнена ровно одна ветка `payload`. Номера полей внутри сообщения — часть контракта.

---

## common.proto

### ContentType

Вид тела сообщения в чате.

| Значение | Смысл |
| --- | --- |
| `CONTENT_TYPE_UNSPECIFIED` | Нулевое значение. Не является телом сообщения. |
| `CONTENT_TYPE_TEXT` | Текст. `content` — текст сообщения. |
| `CONTENT_TYPE_IMAGE` | Изображение. `content` — ключ объекта в хранилище. |
| `CONTENT_TYPE_VIDEO` | Видео. `content` — ключ объекта в хранилище. |
| `CONTENT_TYPE_FILE` | Файл. `content` — ключ объекта в хранилище. |
| `CONTENT_TYPE_VOICE` | Голос. `content` — ключ объекта в хранилище. |

`CONTENT_TYPE_MEDIA` зарезервировано и не является телом сообщения.

### FileInfo

Один файл установки клиента.

| Поле | Тип | Смысл |
| --- | --- | --- |
| `name` | `string` | Имя файла. |
| `path` | `string` | Путь относительно установки. |
| `hash` | `string` | Хеш содержимого. |

### DirInfo

Один каталог. `path` — путь каталога.

### MainExecutable

Имя главного исполняемого файла клиента. `name` — это имя.

### FileSet

Снимок установки: `files`, `directories` и `main_executable`. Клиент отправляет этот снимок как `ClientMessage.file_hashes` (что у него есть сейчас). Сервер отправляет его как `ServerMessage.file_manifest` (до чего клиент должен обновиться).

---

## client.proto

`user_id` в `ClientMessage` — отправитель. В телах пакетов он не повторяется.

### ClientMessage

Конверт клиента. `user_id` задаёт отправителя. `payload` — ровно одно из сообщений ниже.

### Connect

Первый пакет после установки соединения. `public_key` — публичный ключ клиента.

### PublicKeyRequest

Запрос публичного ключа пользователя `user_id`. Сервер отвечает `PublicKey`. `ClientMessage.user_id` остаётся отправителем и не подменяет это поле.

### PresenceRequest

Сетевое состояние пользователя `ClientMessage.user_id`. `online` равен `true`, когда пользователь в сети, и `false`, когда он выходит из сети.

### SendMessageRequest

Новое сообщение в чат.

| Поле | Тип | Смысл |
| --- | --- | --- |
| `chat_id` | `uint64` | Чат назначения. |
| `content` | `string` | Текст, либо ключ объекта в хранилище, если `content_type` не `CONTENT_TYPE_TEXT`. |
| `content_type` | `ContentType` | Как читать `content`. |
| `temp_message_id` | `uint64` | Идентификатор, созданный клиентом. Сервер возвращает его в `MessageCreated`. |

### ReadMessageRequest

Отправитель прочитал сообщение. `chat_id` — чат. `message_id` — сообщение.

### EditMessageRequest

Замена тела существующего сообщения. `chat_id` и `message_id` выбирают его. `content` и `content_type` читаются так же, как в `SendMessageRequest`.

### PinMessageRequest

Закрепить или открепить сообщение. `pinned` равен `true`, чтобы закрепить, и `false`, чтобы снять закрепление.

### DeleteMessageRequest

Удаление сообщения. `chat_id` и `message_id` выбирают его.

### TypingRequest

Состояние набора текста в чате. `is_typing` равен `true`, пока пользователь печатает, и `false`, когда он остановился.

### UnreadCountRequest

Запрос числа непрочитанных сообщений в `chat_id` для `ClientMessage.user_id`. Сервер отвечает `UnreadCount`.

### DownloadFileRequest

Запрос одного файла обновления. `path` — путь файла. Сервер отвечает `DownloadFileResult`.

---

## server.proto

### ServerMessage

Конверт сервера. `payload` — ровно одно из сообщений ниже.

### PresenceEvent

Сетевое состояние пользователя. `user_id` — этот пользователь. `online` — новое состояние.

### TypingEvent

Набор текста пользователя в чате. `user_id` — этот пользователь. `chat_id` — чат. `is_typing` равен `true` во время набора и `false`, когда набор прекратился.

### MessageCreated

Сообщение сохранено и его можно показать.

| Поле | Тип | Смысл |
| --- | --- | --- |
| `temp_message_id` | `uint64` | Идентификатор из `SendMessageRequest`. `0` для всех, кроме отправителя. |
| `message_id` | `uint64` | Серверный идентификатор сообщения. |
| `chat_id` | `uint64` | Чат, которому принадлежит сообщение. |
| `sender_id` | `uint64` | Автор. |
| `content` | `string` | Текст, либо ключ объекта в хранилище, если `content_type` не `CONTENT_TYPE_TEXT`. |
| `content_type` | `ContentType` | Как читать `content`. |
| `created_at` | `Timestamp` | Время создания строки сообщения. |
| `is_edited` | `bool` | Сохранённое сообщение уже изменяли. |
| `is_pinned` | `bool` | Сохранённое сообщение закреплено. |

### MessageRead

Пользователь прочитал сообщение. `chat_id` и `message_id` выбирают его. `user_id` — кто прочитал. `read_at` — когда это прочтение записано. Тот же пакет является квитанцией прочтения для автора.

### MessageEdited

Тело сообщения заменено.

| Поле | Тип | Смысл |
| --- | --- | --- |
| `message_id` | `uint64` | Изменённое сообщение. |
| `chat_id` | `uint64` | Чат. |
| `sender_id` | `uint64` | Автор правки. |
| `content` | `string` | Новое тело. |
| `content_type` | `ContentType` | Как читать `content`. |
| `edited_at` | `Timestamp` | Время правки. |

### MessageDeleted

Сообщение удалено.

| Поле | Тип | Смысл |
| --- | --- | --- |
| `chat_id` | `uint64` | Чат. |
| `message_id` | `uint64` | Удалённое сообщение. |
| `user_id` | `uint64` | Кто удалил. Для модерации это действующий пользователь, либо пусто, если его нет. |
| `deleted_at` | `Timestamp` | Время записи удаления. |
| `reason` | `MessageDeleted.DeleteReason` | Почему сообщение удалено. |

`MessageDeleted.DeleteReason`:

| Значение | Смысл |
| --- | --- |
| `DELETE_REASON_UNSPECIFIED` | Нулевое значение. Причина не задана. |
| `DELETE_REASON_USER` | Удалил пользователь. |
| `DELETE_REASON_MODERATION` | Снято модерацией. |

### MessagePinned

Состояние закрепления. `user_id` — кто его изменил. `chat_id` и `message_id` выбирают сообщение. `pinned` равен `true`, когда сообщение закреплено, и `false`, когда закрепление снято.

### UnreadCount

Ответ на `UnreadCountRequest`. `chat_id` — чат. `count` — число непрочитанных сообщений.

### PublicKey

Ответ на `PublicKeyRequest`. `user_id` — владелец ключа. `public_key` — публичный ключ этого пользователя.

### Disconnect

Сервер закрывает соединение.

| Поле | Тип | Смысл |
| --- | --- | --- |
| `reason` | `Disconnect.DisconnectReason` | Почему соединение закрывается. |
| `description` | `string` | Пояснение для человека. |
| `code` | `int32` | Код приложения. |
| `blocked_until` | `Timestamp` | Конец временной блокировки аккаунта. Не задано, если блокировка не временная. |
| `permanent` | `bool` | Блокировка аккаунта без срока. |

`Disconnect.DisconnectReason`:

| Значение | Смысл |
| --- | --- |
| `DISCONNECT_REASON_UNSPECIFIED` | Нулевое значение. Причина не задана. |
| `DISCONNECT_REASON_WARN` | Предупреждение. |
| `DISCONNECT_REASON_ERROR` | Ошибка. |
| `DISCONNECT_REASON_TEMP_BAN` | Временная блокировка. |
| `DISCONNECT_REASON_INACTIVE` | Соединение простаивает. |
| `DISCONNECT_REASON_INSUFFICIENT_INFO` | Клиент не прислал обязательные данные. |

### DownloadFileResult

Ответ на `DownloadFileRequest`. `file` — `FileInfo` запрошенного файла.
